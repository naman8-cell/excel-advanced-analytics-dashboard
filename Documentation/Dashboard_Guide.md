Dashboard Guide

1. Dashboard Purpose

The Executive Dashboard provides a consolidated view of project delivery metrics, helping users review project counts, budgets, costs, business value, completion progress, and project status.

2. Key Performance Indicators

- Total Projects: Number of projects represented in the dashboard.
- Total Budget: Combined budget displayed by the workbook.
- Actual Cost: Total actual cost displayed by the workbook.
- Business Value: Combined business value represented in the data.
- Average Completion: Average project completion percentage.
- Cost Variance: Difference between budget and actual cost, according to the workbook's calculation.
- Value-to-Cost Ratio: Relationship between business value and actual cost.
- High-Risk Projects: Project count identified by the workbook's risk criteria.

3. Dashboard Visualizations

Project Count by Status

Summarizes the number of projects across the displayed status categories.

Monthly Budget vs Actual Cost

Compares budget and actual cost over time.

Business Value by Region

Shows how recorded business value is distributed across regions.

4. Filters and Interactivity

The dashboard displays region and status selection controls. Test these controls in the workbook to confirm how they affect the displayed results.

5. Interpreting Results

Use the dashboard to review project distribution, compare planned and actual costs, and identify metrics that may need further investigation.

All KPIs should be interpreted according to their underlying formulas, data definitions, and risk criteria.

6. Important Note

The dashboard is an Excel portfolio project. Figures and findings should not be interpreted as actual business performance unless they have been verified against an authorized real dataset.
